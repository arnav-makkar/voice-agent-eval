Phone Tier Call Sheet

Fifteen cards against the v4 champion. Every card names the tool writes that must appear in the journal, the lines to say, and the two commands that run it. The journal is the only evidence about tools — what the agent says it did never counts.

Before the session

bash scripts/preflight_phone.sh

Five checks, and each one exists because it already cost a run: the deployed prompt is byte-identical to the committed champion (667ce12e2626c75e); the agent's clock is today's; the tool service answers; the gate accepts the key; and a real turn from the deployed agent reaches the journal. If it prints anything but ALL GREEN, don't dial — a call on a red preflight burns credits and produces evidence you can't trust.

Per call

.venv/bin/python scripts/place_phone_call.py --card N   # seeds ledger c2-phone-NN, dials
bash scripts/phone_call.sh N                            # after you hang up: reads and scores

The dial request carries this card's campaignId, so each call writes to its own ledger key and two calls can never be confused for one another. The clock is derived from the real calendar at dial time, overriding whatever date the scenario was authored against.
