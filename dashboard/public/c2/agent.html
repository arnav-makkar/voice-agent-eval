Step one · build

First, an agent worth testing

A framework proves nothing against a toy. So the subject is a real, deployed voice agent on Sarvam Indus: an EMI collections agent that calls customers in Hindi and Hinglish about an overdue instalment.

The loan

A Samsung Smart TV bought on EMI. Rs 4,416 overdue, instalment 7 of 12, 17 days late.

The tools

Six actions it can take: check the balance, log a promise, file a dispute, book a callback, escalate to a human, record the outcome.

The stakes

Almost every outcome of a call is a record it must write. That makes it a hard, honest test for execution truth.

PropertyValue
PlatformSarvam Indus, deployed and live; every test in this study ran against the real deployed agent, never a copy

Hear it before any numbers

Judge the baseline the way a customer would: by listening. These jump straight into the call browser with the original agent selected.

What you will hear: a polite, fluent, competent-sounding agent. The next section is about why sounding competent is not the same as being correct, and how that difference is measured.
