Section 7 · Limits, roadmap, references

What this does not claim — and what comes next

Strong numbers stay credible only if their boundaries are stated by the person presenting them, before anyone else finds them. These are the boundaries.

Limits

  • The voice tiers are small. n = 15 and n = 5 carry no statistics. They are existence proofs that the text-tier gains transfer to the voice channel — the statistics live in the 180-scenario text tier.
  • One phone card's fix is confounded. Baseline card 6 was conducted in English (the caller switched; the agent correctly mirrored); the champion re-run was Hinglish. Its fix is real on the ledger but not isolated from the language change.
  • Duplicate writes moved rather than resolved. Exactly-once hygiene is 14/15 on both phone versions: the baseline's triple write on card 11 is gone, a new double write appeared on card 13. On the bot tier it improved 2/5 → 4/5 with one residual.
  • Compounding is not established. Gen 1 → Gen 2 is +5 overall at p = 0.18 — positive and regression-free, not significant. Two rungs demonstrate the loop runs repeatedly; they do not prove indefinite improvement.
  • Surface form costs something. With every caller line reworded, the champion drops 29 → 26 while the baseline drops 18 → 17: about 82% of the advantage survives rewording, and about 18% of it is phrasing-sensitive.
  • Persuasion was never an objective. The agent accepts a first refusal because its prompt — including a mined exemplar — teaches exactly that. The loop optimised execution truth, not collection rate. That is a scope choice, stated here so no listener discovers it as a surprise.
  • One account, scripted callers, uniform family mix. Right for covering rare and dangerous cases with n = 12 each; not a forecast of production traffic distribution.

Platform findings surfaced along the way

FindingDetail
Inactivity nudge registerThe runtime's stock Hindi nudge — spoken after 5 s of caller silence — is "अरे, है क्या तू?": the intimate/disrespectful second person, injected into a call that says आप and जी throughout. Caught because the harness reads every transcript. The nudge text is platform configuration regenerated from an English source string, outside the agent prompt.
Channel variable asymmetryPhone and duplex-voice channels accept per-call agent variables; the text-chat REST channel silently ignores them and uses stored defaults — which decides which ledger key a run writes under. Every tier's isolation strategy follows from this.
Draft-serving runtimeThe runtime serves the mutable draft directly (is_deployed: false throughout); the version label is a revision counter, not a release pointer. Version pinning therefore lives in this project's sha checks, not in the platform.
Split-model promptingConversation runs on Sarvam Pro; tool calling runs on Llama 3.1 70B. Every tool-discipline gain here was achieved by prompt text steering the smaller model — worth knowing when writing tool rules for this stack.
