A voice agent that diagnosed and corrected its own failures

It used to promise customers things it never actually recorded. An automated loop found that habit, rewrote the agent to remove it, and proved the fix on 200 conversations including 20 real phone calls.

Nine in ten conversations now end correctly, up from five in ten.

No person wrote the fix. The system diagnosed the failure, generated the correction, tested it against cases it had never seen, and shipped it.

What the agent actually does

It calls customers whose loan instalment is overdue, in Hindi and Hinglish, and tries to resolve the situation: take a payment, agree a date, book a callback, log a dispute, or escalate to a human being.

The loan

A Samsung Smart TV bought on EMI. ₹4,416 overdue, instalment 7 of 12, 17 days late.

The tools

Six actions it can take: check the balance, log a promise, file a dispute, book a callback, escalate to a human, record the outcome.

The catch

Saying it did one of those things is not the same as doing it. That gap is the whole story.

Three separate proofs

A result that only shows up in one kind of test is a result you should not trust. This one was measured three independent ways, and all three moved together.

Why three tiers instead of one big test

Each tier answers a question the others cannot.

  • Typed chat is cheap enough to run 180 times, so it is the only tier that can carry statistics.
  • Phone calls put a real person on a real line with real speech recognition, interruptions and background noise. Nothing is retryable.
  • Voice to voice has a synthetic caller speak to the agent over live audio, which makes voice behaviour repeatable in a way a human caller never is.

The statistics live in the first tier. The other two exist to show the gains survive contact with real speech.
