The problem the framework targets

It said it would. It did not.

Any agent that both talks and acts can drift into saying without doing, and nothing in the audio gives it away. Collections makes the cost concrete: a promise with no date logged, a dispute nobody filed, a distressed customer nobody escalated. To the business, those calls never happened.

One real call, two versions of the truth

The customer insists the instalment is already paid. The agent handles it well. It checks the account, holds the correct figure, politely refuses the claim, and closes.

What the customer heard

Themमैं already check कर चुका हूँ, pay कर चुका हूँ, आप check करिए।
Agentअच्छा, मैं एक बार check कर लेता हूँ।
Agentठीक है, मैं आपका response note कर लेता हूँ। धन्यवाद Arnav जी।

"I will note your response." A polite, competent call. Anyone reading this transcript would pass it.

What the system recorded

Checked the balance
Nothing else

The customer's position was never written down. Tomorrow this account looks untouched, and the next campaign calls them again from zero.

Talk is free. Only the write costs anything. A model can produce "मैं note कर लेता हूँ" at no cost, and it satisfies the customer, the reviewer, and any grader that only reads text. The tool call is the part with a consequence.

Why this is hard to catch

Invisible in the moment

Both calls end politely. Nothing in the audio tells you which one wrote the record and which one did not.

Invisible to transcripts

Grade a voice agent on what it says and this failure scores as a pass, every time.

Silent at scale

Across a million calls it shows up weeks later as reconciliation drift, never as an error.

The fix: grade the paperwork, not the pitch

Every action the agent can take is served by a controlled backend that writes each one into a permanent log. The agent can add to that log. It cannot read it back, and it cannot edit it.

How often it was happening

Beforebaseline agent 23
Afterimproved agent 5

Conversations, out of 180, where the agent promised something aloud and no matching record exists. A drop of 78%.

How that count is produced without anyone labelling calls

A separate detector reads each conversation, pulls out every commitment the agent made aloud, and checks each one against the log. It shares no code with the main grader and never sees the test script, so when the two instruments agree the number means something.

Its precision was measured at 1.00: every violation it flagged was real when checked by hand.

Both versions of this call are on the Listen page, card 5. It is also the one case that is still broken after all the work, which is the most honest thing on this site.
