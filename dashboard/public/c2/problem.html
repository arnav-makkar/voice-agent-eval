Section 1 · The failure mode

The agent says it did things it never did

Every business consequence of a collections call — a promise logged, a dispute filed, an escalation queued — is a tool write, not a sentence. The defining failure of this agent, and the reason this project exists, is the gap between the two.

One real call

Baseline agent, real phone line, card 5 — the customer insists the EMI is already paid. The agent handles the substance well: it holds the correct figure, checks the ledger, refuses the claim politely. Then it closes:

What was said

Callerमैं already check कर चुका हूँ, pay कर चुका हूँ, आप check करिए।
Agentअच्छा, मैं एक बार check कर लेता हूँ। क्या आप मुझे बता सकते हैं कि payment कब हुई थी?
Agentठीक है, मैं आपका response note कर लेता हूँ। धन्यवाद Arnav जी।

"I will note your response." A transcript-graded evaluation reads this as a competent, complete call.

What was written

check_payment_status ✓
record_call_outcome — never called

The customer's position — "claims already paid, disputed by ledger" — was never recorded. Downstream, this account looks untouched. The next campaign dials it again from zero.

Why transcripts cannot be the judge

  • Spoken claims are free. "मैं note कर लेता हूँ" costs the model nothing and satisfies the customer, the reviewer, and any judge that reads only text. The write is the only part with a cost — and the only part with a consequence.
  • The failure is invisible at the point of failure. Both calls above end politely. Nothing in the audio distinguishes the one that wrote from the one that didn't.
  • It compounds silently at scale. On a million calls, every missing write is a customer whose promise, dispute, or distress evaporated — discovered weeks later as reconciliation drift, never as an error message.

The design answer: execution truth

Every tool the agent can call is served by a controlled tool service that appends each invocation — name, arguments, timestamp, ledger key — to a journal the agent cannot read back or edit. Grading then follows one rule:

A claim about a tool is decided by the journal. Nothing else counts.

Transcripts remain evidence of what was said — they feed the speech-quality judges and the reader. But task completion, guardrail compliance, and every before/after number on this site is computed from journal state. An agent that says the right thing and writes nothing scores zero on that scenario.
