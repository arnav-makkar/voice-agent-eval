Reading the grid honestly. Most thresholds are lenient (≥ 0.5), so a call can improve substantially inside a single unchanged ✓ — the distress call's conciseness rose 0.667 → 1.0 and progression 0.5 → 1.0, both audible in the recordings. Turn-taking shows “–” because its per-turn audio segments come back empty in this harness: a zero that means “no data” is excluded, never averaged in. And the one red cell that survives — duplicate writes on the dispute call — is the honest residue: v4 is better, not perfect.

The one that stayed broken

Card 5, already-paid, fails on both versions the same way. The champion checks the ledger, holds the figure, says "मैं आपका response note कर लेता हूँ" — and writes nothing. The one remaining P0 behaviour, in exactly the say-vs-do shape the instrument exists to catch. It is the first target of the next loop iteration, and it is presented here rather than hidden because a result with a visible residual is more credible than a perfect scoreboard.
