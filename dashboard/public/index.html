Executive summary

A Framework for Evaluation and Self-Improvement of Voice Agents

Voice agents are usually evaluated on their transcripts. This framework grades them on the records they leave in the business systems they act on, and uses those failures to improve the agent.

How it works

Domain-agnostic by construction. Nothing in the loop is specific to collections. Onboarding a new agent requires its tool list, the end state each situation should produce, and the failure types that matter in its domain.

Validated on a live agent

An EMI collections agent deployed on Sarvam Indus, in Hindi and Hinglish. 200 real conversations across phone calls, bot-to-bot voice, and text.
