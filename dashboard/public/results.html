The filed defects, re-tested

Six defects were filed during evaluation, each with a severity and the evidence behind it, before any fix was attempted. Each names the calls it was raised on, and closes only when all of them pass a re-dial.

#The original defectWhat happens nowStatus
1Handles it perfectly, records nothingThe dispute call now files the dispute and the outcome. The already-paid call still says it will note the response and writes nothing.part closed
2A fraud report filed as refused to payThe fraud call now escalates to a human, once, and records the outcome once. The triple write is gone.closed
3Escalation logged, no human actually calledThe hand-off now happens before the outcome is recorded, so a person is genuinely queued.closed
4"I will pay by this evening" never became a dateThe promise and the resolved calendar date are both written now.closed
