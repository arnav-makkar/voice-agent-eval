## Fixed evaluation clock

The control prompt fixes today as `17-08-2026` and tomorrow as `18-08-2026`. No extra date variables are needed for this controlled dataset.

## Output fields

These start blank/default and are extracted after the call: `callbackDateTime`, `callSummary`, `disposition`, `escalationComment`, `escalationReason`, `identityConfirmed`, `promisedToPayDate`, and `userUpdatedNumber`.

The checked-in `examples/emi-reminder.variables.json` is the canonical outbound override for the frozen voice fixture. The richer offline contracts are generated by `dataset/generate_scenarios.py` and never sent to a real customer.
